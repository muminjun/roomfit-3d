# 3D viewer report

The lazy-loaded `Viewer3D` renders the same committed room and furniture used by 2D, using React Three Fiber and OrbitControls. Floor triangles use the specified ShapeGeometry coordinate conversion and upward normals. Walls are the union of outward edge strips and convex-corner patches, partitioned at strip and room coordinates, with interior cells removed and side faces emitted only at exposed neighboring cells. Geometry and furniture resources are memoized and disposed on replacement/unmount. Furniture uses low-poly kind-specific representations constrained to its exact dimensions, and rotations map to negative Three.js yaw.

Camera framing uses the specified eight-corner calculation at the current canvas aspect; both camera controls recompute the fit. The viewer checks WebGL before mounting, handles context loss, and exposes a retry fallback without changing project data. Browser verification of rendering, context loss, retry and integration is a separate gate owned by the UI integration work.

Tests were written before the missing geometry module was implemented; the initial run failed with module-not-found. `npm test -- --run tests/unit/viewer3d.test.ts` passed 8 tests including R/U/P floors and normals, exact model mapping, rectangular corner patches, L/U and 100/200mm notch walls at 500mm thickness, no overlapping cells or duplicated triangles, no sides on shared cell boundaries, 20 furniture bounds, rotation, and camera projection at four aspect ratios. A full `npm test` run passed 78 tests; `npm run lint` and `npm run build` passed. The build warns about large minified chunks (main 702.50 kB, lazy viewer 938.40 kB); no threshold was raised. No frame rate claim is made without measurement.

The 500 × 500 × 5000mm legal room needs a camera distance greater than six times its floor diagonal; the OrbitControls maximum is therefore `max(6 × diagonal, fitted distance)` so it does not clamp away the required fit. The standard room retains `6 × diagonal`. A regression test observed the missing limit fail before this adjustment. Semi-transparent walls let the interior remain visible; this affects rendering only, not the wall geometry.
