# Project JSON report

`parseProjectJson` checks the actual UTF-8 byte count, schema version and strictly shaped data, rejects forbidden prototype-related keys and duplicate IDs, and checks the raw polygon for repeated points, non-orthogonal edges, crossings, touches and backtracking before normalization. It then normalizes safe collinear midpoints or counterclockwise winding, validates the final structure, converts unknown catalog types to `other`, and returns changes and derived placement warnings. It performs no store, UI or storage mutations. Existing invalid furniture remains present. `serializeProjectJson` explicitly projects allowed persisted fields, and `projectFilename` limits the safe Unicode filename component to 50 code points.

The tests were written before implementation and initially failed because the module was missing. Additional regressions for deep nesting and Unicode C1 control characters were each observed failing and then passing after fixes. The focused suite passes 9 tests, including invalid input, 64/100 limits, round-trip metadata and IDs, winding, raw geometry, unknown catalogs, warnings, and filenames. The full suite passed 91 tests; lint and production build (including TypeScript) passed. Build reports the existing large-chunk warning. Browser import confirmation and autosave interactions are separate integration checks.

Additional review verified that a 50mm collinear intermediate edge is removed before the minimum-length check, while a remaining 99mm edge is rejected. The prototype-key walk is iterative; 20,000-level malformed and nested `__proto__` inputs return errors without recursion failure. Project and furniture renames now strip Unicode `Cc` controls consistently with the schema; both regressions failed before the fix and passed after it. The latest complete unit run passed 92 tests.

Furniture center coordinates are constrained to finite safe half-millimeter values rather than the polygon's ±30,000mm coordinate limit. A 31,000mm center now imports unchanged with an outside-room warning; unsafe half-millimeter values and Infinity remain invalid. This regression was observed failing before the correction and passing afterward. The subsequent complete unit run passed 97 tests; lint and typecheck passed.
