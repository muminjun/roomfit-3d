# 미검증 환경과 수동 확인 절차

현재 AC별 실제 증거는 `ac-evidence-2026-11-03.md`, 명령 결과는 `TEST_REPORT.md`를 따른다. 자동 테스트 개수는 아래 환경을 직접 확인했다는 뜻이 아니다.

## Safari

설치된 Safari 27.2의 WebDriver 세션은 Remote Automation 비활성으로 HTTP500을 반환했다. 시스템 설정은 변경하지 않았다. WebKit 결과로 Safari 통과를 대신하지 않는다.

사용 가능한 Safari에서 서비스의 새 공간 생성→책상 추가→Y1755입력→Space팬→Shift가로이동→회전/오류복구→문·창문·구역 추가→3D→JSON내보내기→새로고침 복원을 확인한다. Space팬 후 가구 좌표/치수/Undo/저장본이 불변이고 Shift드래그 후 Y가 정확히1755인지 확인한다. 이 절차는 아직 실행 결과가 아니다.

## 스크린리더

실제 스크린리더 청취는 미실행이다. 사용 가능한 환경에서 Tab/Shift+Tab으로 새 공간 생성, 카탈로그 추가, 가구 이름/치수 수정, 잘못된 치수 해결, 삭제/Undo, JSON백업, 2D/3D 전환을 진행한다. 입력 라벨·단위·범위·오류가 함께 읽히고, modal 포커스가 갇혔다가 원래 위치로 돌아오며, 드래그 프리뷰마다 aria-live가 반복 발화하지 않는지 확인한다. 관련 자동 키보드 여정은 실제 청취 검증과 구분한다.

## 물리 트랙패드·핀치·마우스

자동 Wheel/Pointer 이벤트 검증만 수행했으며 실제 장치 체감은 미검증이다. 두 휠 모드에서 휠/Shift휠/Ctrl·Cmd·Alt휠/물리핀치가 포인터 아래 world좌표를 유지하는지 확인한다. 가구·코너핸들·벽 위에서 Space 및 중간 버튼 팬을 시작하고, Esc·blur·이탈·pointercancel·도구/뷰 전환 후 다음 조작이 정상인지 확인한다. 도면 JSON과 Undo가 팬 때문에 변하면 실패다.

## 성능

`tests/e2e/performance.spec.ts`는 별도 컨텍스트의30벽/50가구 데이터를 사용한다. `?measure=1`의3D진단에서 draw calls, triangles, 실제 렌더프레임 간격과 CPU제출 시간을 관찰한다. GPU타이머가 없는 환경의 CPU값이나 rAF cadence를 GPUfps로 바꾸어 말하지 않는다. 지속30fps목표는 실제대상기기에서 별도 측정해야 한다. 기록된 표본은 `performance-2026-11-03.json`을 참조한다.

## Edge

사용자 지시로 검증을 중단하고 내려받은 패키지·추출앱·이번 실행에서 생성된 지원데이터/환경설정·프로세스를 삭제했다. 다시 설치하거나 실행하지 않는다. 실제 Edge의 제품 여정은 미검증으로 남긴다.
